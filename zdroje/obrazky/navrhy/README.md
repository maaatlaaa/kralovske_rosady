# Návrhy ilustrací

Kandidáti na nové ilustrace karet, roztřídění podle nástroje, kterým vznikli.
Soubory se jmenují stejně jako v `karty_podklady/` (např. `julie`), aby šly
karty z různých nástrojů porovnat vedle sebe.

- `chatgpt/`: ChatGPT (hlavní sada)
- `bing/`: Bing Image Creator, režim „Živé a přirozené“ (MAI-Image-2.6-Flash)

Obrázky poslané přes chat jsou překomprimované. Originály v plném rozlišení
je potřeba uchovat zvlášť, než vybraná ilustrace přejde do `karty_podklady/`.
